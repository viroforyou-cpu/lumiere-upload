# 02_consult — agree the services and products

One job: turn the client's request into a concrete service + product list. Run by the
receptionist together with the stylist/assistant as needed.

## Inputs

- Working: `../01_check-in/output/check-in.md`
- Reference: `_shared/service-menu.md`
- Reference: `_shared/pricing.md`
- Reference: `records/clients/<id>/preferences.md`

## Process

1. Read the check-in file.
2. Map the client's request to services from `service-menu.md`, noting men or women line.
3. Pick retail products the client wants from the menu/pricing.
4. Record a preliminary staff assignment (stylist; assistant if hair washing is involved).

## Outputs

- `consult.md` → `output/`: selected services, products, requested staff.

## Human check

Receptionist reads the list back to the client and confirms. Anything unlisted must be added
to the menu/pricing before it can be billed.
