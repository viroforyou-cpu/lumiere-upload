# 00-today — Today's dashboard (receptionist screen)

Professional, modern, dark background with gold accent, bilingual (EN/ES), and easy for
non-technical receptionists. Generated by the analytics engine from `analytics/output/` and
today's tickets. It is rebuilt from records — never hand-edited for numbers.

## Cards shown (in this order)

`today_sales`, `tickets`, `revenue`, `products_sold`, `new_clients`, `returning_clients`,
`no_shows`

Labels are rendered from `_shared/i18n/en.md` and `es.md` — the dashboard stores only keys,
never the English/Spanish text itself.

## Payments today

Split by method (cash / card / mobile / gift card / voucher), amounts in ARS. Method labels
come from `_shared/i18n/`.

## Rules

- Big numbers first; no jargon; the receptionist never navigates beyond this screen.
- This file holds keys and layout only — no content payload, no duplicated labels.
- It never contains commission or tip data.
